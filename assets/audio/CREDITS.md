# Emberfall audio: where every file came from

All files here were listed as **CC0 1.0** (public domain dedication) on their source pages when downloaded on
11 November 2026. No attribution is required; this list is kept so each asset can be re-checked before a commercial release.
The packs' own license files are in `licenses/`.
